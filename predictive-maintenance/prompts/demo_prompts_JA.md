# デモプロンプト — 予知保全（Predictive Maintenance）

### --- 1. データ探索・理解 ---

**プロンプト 1-1: テーブル探索**
```
SF_SOLUTIONSに製造業のIoTデータがあります。PRED_MAINT_RAWスキーマのテーブルを確認して、どんなデータがあるか教えてください。行数、主要カラム、データ期間を要約してください。
```

**プロンプト 1-2: センサーデータのプロファイリング**
```
SF_SOLUTIONS.PRED_MAINT_RAW.SENSOR_READINGSテーブルをプロファイリングしてください。
- データ期間と計測頻度
- 監視対象の設備数
- センサー種別（温度、振動等）
- 明らかな外れ値や欠損
を教えてください。
```

**プロンプト 1-3: センサートレンドの可視化**
```
SF_SOLUTIONS.PRED_MAINT_RAW.SENSOR_READINGSから、過去6ヶ月の設備別・日次平均振動トレンドを折れ線グラフで表示してください。上昇トレンドのある設備をハイライトしてください。
```

---

### --- 2. MLモデル構築（異常検知）---

**プロンプト 2-1: 特徴量エンジニアリング**
```
SF_SOLUTIONS.PRED_MAINT_ANALYTICSに、時間毎のセンサーデータを設備×日次で集計した特徴量ビューを作成してください。温度・振動の平均・最大・標準偏差、電流の平均・最大を含めてください。
```

**プロンプト 2-2: 異常検知モデル構築**
```
Snowflake ML Anomaly Detectionを使って、SF_SOLUTIONS.PRED_MAINT_ANALYTICSにEQUIPMENT_ANOMALY_MODELを構築してください。EQUIPMENT_IDをシリーズ列、READING_DATEをタイムスタンプ、AVG_VIBRATIONをターゲットにしてください。99%信頼区間を使用してください。
```

**プロンプト 2-3: 異常検知の実行と保存**
```
最新のセンサーデータに対して異常検知を実行し、結果をSF_SOLUTIONS.PRED_MAINT_ML.ANOMALY_RESULTSに保存してください。設備ID、日付、実測値、予測区間、異常フラグを含めてください。
```

**プロンプト 2-4: 異常の調査**
```
過去30日間で異常が最も多い設備はどれですか？設備別の異常件数と平均重大度の内訳を表示してください。ワースト3の設備について異常な読み取り値を可視化してください。
```

---

### --- 3. 健全性スコア・アラート ---

**プロンプト 3-1: 設備健全性スコア**
```
以下を組み合わせた設備健全性スコアリングシステムを作成してください：
1. 過去30日間の異常検知頻度
2. 過去1年の事後保全（計画外）件数
3. 前回保全からの経過日数
4. 異常の重大度（期待値からの乖離）

各設備を0-100でスコアリング（100=健全）し、ステータスを割り当て: CRITICAL, WARNING, MONITOR, HEALTHY。EQUIPMENT_HEALTH_SCOREビューとして作成してください。
```

**プロンプト 3-2: アラートダッシュボード**
```
今すぐ対応が必要な設備はどれですか？CRITICALまたはWARNINGステータスの全設備を、健全性スコア・異常件数・前回保全からの日数とともに表示してください。健全性スコア順の棒グラフで可視化してください。
```

**プロンプト 3-3: 工場サマリー**
```
工場別のサマリーを表示してください。工場ごとの健全/リスク有り設備数、平均健全性スコア、過去1年の総ダウンタイム時間を含めてください。
```

---

### --- 4. エンドツーエンド実行 ---

**プロンプト 4-1: 全パイプラインデモ**
```
予知保全パイプラインの全ステップを実行してください：
1. SF_SOLUTIONSのセンサー・設備データを確認
2. 生センサーデータから日次特徴量集計を作成
3. 異常検知モデルを構築
4. 異常を検知し、リスクのある設備を特定
5. 設備健全性をスコアリングし、保全アラートを生成
6. 今すぐ対応が必要な設備をまとめて報告

各ステップの結果を途中で見せてください。
```
