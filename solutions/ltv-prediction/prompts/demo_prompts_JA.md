# デモプロンプト — 顧客生涯価値（LTV）予測

### --- 1. データ探索 ---

**プロンプト 1-1: 取引データのプロファイリング**
```
SF_SOLUTIONS.LTV_RAW.ML_LTV_TRANSACTIONSテーブルをプロファイリングしてください。データ期間、顧客数、総取引数、商品カテゴリ別・チャネル別の内訳を教えてください。
```

**プロンプト 1-2: 顧客行動分析**
```
SF_SOLUTIONS.LTV_RAW.ML_LTV_TRANSACTIONSの取引パターンを分析してください。月次取引量のトレンドと総支出額上位10顧客を表示してください。月次トレンドを折れ線グラフで可視化してください。
```

---

### --- 2. 特徴量の探索 ---

**プロンプト 2-1: 特徴量プロファイル**
```
SF_SOLUTIONS.LTV_ANALYTICSのCUSTOMER_FEATURESテーブルをプロファイリングしてください。total_spend、txn_count、recency_daysなど主要特徴量の分布を表示し、FUTURE_LTVとの相関が高い特徴量はどれか分析してください。
```

---

### --- 3. モデル評価 ---

**プロンプト 3-1: モデル指標**
```
SF_SOLUTIONS.LTV_ANALYTICSのLTV_REGRESSION_MODELの評価指標を表示してください。R²、MAE、RMSEは？特徴量重要度も表示して、最も重要な特徴量はどれか教えてください。
```

**プロンプト 3-2: 予測精度**
```
SF_SOLUTIONS.LTV_ML.LTV_PREDICTIONSの予測値と実績値を比較してください。LTV範囲バケット別の平均絶対誤差を表示し、予測vs実績の散布図を可視化してください。
```

---

### --- 4. 顧客セグメント ---

**プロンプト 4-1: セグメントサマリー**
```
SF_SOLUTIONS.LTV_ANALYTICS.CUSTOMER_SEGMENTSの顧客セグメントを表示してください。各セグメント（Platinum/Gold/Silver/Bronze）の顧客数、平均予測LTV、平均過去支出額、平均取引頻度を棒グラフで可視化してください。
```

**プロンプト 4-2: Platinum顧客の深掘り**
```
Platinum顧客は誰ですか？予測LTV上位20名を主要指標とともに表示してください。Bronze顧客との行動の違いは何ですか？
```

---

### --- 5. エンドツーエンド ---

**プロンプト 5-1: 全パイプラインレビュー**
```
SF_SOLUTIONSのLTV予測パイプラインを説明してください：
1. 生の取引データのサマリーを表示
2. 構築された顧客特徴量を説明
3. モデル評価指標と特徴量重要度を表示
4. 予測精度を分析
5. 顧客セグメントとそのビジネス上の意味をまとめて報告
```
